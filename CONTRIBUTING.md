# Contributing

Read CLAUDE.md before editing. Its shared prefix is copied from ATS015, while the custom portion describes ATS073: OpenTelemetry Certified Associate (OTCA), Fundamentals of Observability (18%), part of ATP015.

Preserve IDs, weights and the existing track registration. Develop self-contained explanations with mechanisms, examples, prerequisites and failure reasoning. Start each section with an introduction and end each module with its own Summary. Keep technical Markdown draft until review.

Every module has a playground and a graded lab, and every section has a capstone lab and a `quiz.yaml`. Labs and playgrounds are built untested: run `astrona validate -c`, `bash -n` and YAML parsing, and do not claim executed results. Quiz files use stable question and option IDs, one correct option and per-option feedback.

Use the primary sources in SOURCES.md and record adaptation paths in AUTHORING.yaml. Review Markdown and questions for semantic correctness as well as structure.
