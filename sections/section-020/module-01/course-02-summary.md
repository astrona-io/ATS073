# Summary

Semantic conventions give producers and consumers shared meanings for telemetry names and attributes. Resource attributes describe the producer, while span, log and metric attributes describe particular observations. Conventions have version and stability boundaries that affect migrations. A standard key does not make every value safe: cardinality, confidentiality and truthful scope still require deliberate design, especially when raw request values or user identifiers are involved.
