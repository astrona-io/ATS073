# Instrumentation

This section covers instrumentation. It develops aPI Calls, Automatic Instrumentation And Measurement Design through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains can include intermediate checkpoints before the final review.

## Learning Outcomes

- Distinguish manual instrumentation from automatic instrumentation.
- Explain API, SDK and exporter responsibilities.
- Select useful boundaries without duplicate or sensitive telemetry.
